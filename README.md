# ChromeExtensionExploring
A simple chrome extension / firefox addon made for a friend to spam a button XD


It's a simple extension with a popup menu with an input field to add a keyword, once the keyword is saved, the extension constantly checks for any button on the current page that includes the keyword in the text contents. It is not case sensitive


I also made a quick test website and a quick discord bot to test different conditions (both included in the source code)
